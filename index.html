🔌 Le Jeu de l'API

Bienvenue ! Une API (Interface de Programmation d'Application), c'est un mot qui fait peur… mais le concept est simple.

Imaginez que vous allez au restaurant. Vous ne rentrez pas en cuisine préparer vous-même votre plat : vous passez par un serveur qui transmet votre commande, puis vous rapporte le résultat.

Une API fonctionne exactement pareil, mais entre deux logiciels (une application et un serveur informatique).

Ce jeu va vous le faire vivre en 4 étapes :

  • 🍽️ Chapitre 1 — Le restaurant (comprendre le principe)
  • 🚨 Chapitre 2 — Quand ça se passe mal (les erreurs)
  • 🧠 Chapitre 3 — Le quiz (vérifier vos connaissances)
  • 🎮 Chapitre 4 — Le simulateur (manipuler une API vous-même)

🍽️ Chapitre 1 — Au restaurant

🙋Vous (le Client)
→
🧑‍💼Le Serveur
→
👨‍🍳La Cuisine

Choisissez un plat sur le menu pour passer votre commande :

🍕 Pizza 🍔 Burger 🥗 Salade
En attente de votre commande…

🍽️ Étape 1 — La Requête

🙋Vous
➡️
🧑‍💼Serveur
👨‍🍳Cuisine

Vous venez d'envoyer votre commande au serveur.

👉 En informatique, cela s'appelle une requête : votre application demande quelque chose à l'API.

🍽️ Étape 2 — L'API transmet

🙋Vous
🧑‍💼Serveur (API)
➡️
👨‍🍳Cuisine

Le serveur ne cuisine pas lui-même : il transmet votre commande à la cuisine.

👉 L'API, c'est exactement ce serveur : elle ne fait pas tout le travail elle-même, elle transmet la demande au bon système (une base de données, un autre logiciel, etc.).

🍽️ Étape 3 — Le traitement

🙋Vous
🧑‍💼Serveur
👨‍🍳Cuisine

La cuisine prépare votre plat : 🔥

👉 C'est le traitement de la requête : le système (base de données, service, etc.) fait le travail demandé "en coulisses".

🍽️ Étape 4 — La Réponse

🙋Vous
⬅️
🧑‍💼Serveur
⬅️
👨‍🍳Cuisine

Le serveur vous rapporte votre plat : 🎉

👉 C'est la réponse : l'API vous renvoie le résultat de votre demande (des données, une confirmation, etc.).

Mais... que se passe-t-il si le plat n'existe pas, ou si la cuisine prend feu ? ⬇️

📋 Récapitulatif du Chapitre 1

Voici la correspondance entre le restaurant et l'informatique :

🙋 Client = Application (site web, appli mobile)

🧑‍💼 Serveur = API

👨‍🍳 Cuisine = Serveur informatique / Base de données

📝 Commande = Requête

🍽️ Plat servi = Réponse (données)
